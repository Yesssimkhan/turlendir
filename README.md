TúrLendir (Түрлендір.kz)
TúrLendir — Қазақстандық онлайн файл түрлендіру порталы (Қазақ нақышындағы CloudConvert баламасы).

🎨 Қазақ нақышындағы дизайн және эстетика
Түстер үйлесімі:

Ашық көк (#0284c7, #0ea5e9): Қазақстан туының негізгі реңкі, бейбітшілік пен ашық аспанды және заманауи технологияны білдіреді.

Алтын сары (#f59e0b, #fbbf24): Дала күні мен қыран бейнесін береді; батырмалар, белгішелер және екпінді элементтер үшін қолданылады.

Түнгі көк (#0a1120, #13213d): Шексіз түнгі дала аспанының түсі, түнгі режимде көзге жайлы орта қалыптастырады.

Ою-өрнек элементтері:

Жоғарғы жақ пен фонға қазақтың дәстүрлі қошқар мүйіз оюы мен күн таңбасының векторлық бейнесі үйлесімді кіріктірілген.

Карталардың жоғарғы жиегіне көк-алтын градиентті жарық жолағы мен отандық белгілер қосылған.

Бренд атауы:

TúrLendir (Түрлендір): «Түрлендіру», «пішімін өзгерту» мағынасын беретін таза қазақи ұғым.

🌟 Негізгі мүмкіндіктер
200+ форматты қолдау: Құжаттар (PDF, Word, TXT), суреттер (PNG, JPG, WEBP), аудио, видео, мұрағаттар, электронды кестелер, таныстырылымдар және электронды кітаптар.

Браузер ішіндегі тікелей әрі жылдам түрлендіру:

Суреттердің сапасын сақтай отырып өзара түрлендіру (HTML5 Canvas негізінде).

Мәтін мен Markdown файлдарын стандартты PDF құжатына айналдыру (jsPDF негізінде).

Бірнеше файлды бірден ZIP мұрағатына жинақтап жүктеу (JSZip негізінде).

Баптаулар панелі: Сурет сапасын реттеу, өлшемін кішірейту, аудио битрейтін баптау және құжат пішімін таңдау.

Қос тақырыптық режим (Күндізгі / Түнгі): Ашық көк және түнгі қою көк реңктер арасында еркін ауысу.

Теңгелік (₸) тарифтік жүйе: Қазақстан нарығына бейімделген баға көрсеткіштері.

🚀 Жобаны іске қосу және орнату
Компьютерде сынап көру
Жоба қалтасындағы index.html файлын екі рет басып, кез келген браузер арқылы ашуға болады.

GitHub Pages арқылы желіге шығару
GitHub жүйесінде жаңа репозиторий ашыңыз (мысалы, turlendir-kz).

Қалтадағы файлдарды (index.html, app.js, styles.css, README.md) жүктеңіз.

Репозиторийдің Settings -> Pages бөліміне өтіп, main тармағын таңдап сақтаңыз. Дайын веб-сілтеме автоматты түрде жасалады.
