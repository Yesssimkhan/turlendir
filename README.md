# TúrLendir (Түрлендір.kz)

**TúrLendir** — Қазақстандық онлайн файл түрлендіру порталы (Қазақ нақышындағы CloudConvert баламасы).
哈萨克风格在线文件转换云平台（TúrLendir / Түрлендір，意为“转换 / Transform”）。

---

## 🎨 哈萨克民族美学与风格设计 (Қазақ нақышындағы дизайн)

1. **色彩哲学 (Түстер үйлесімі)**：
   - **天空蓝 (Ашық көк - `#0284c7`, `#0ea5e9`)**：源自哈萨克斯坦国旗主色调，象征和平、广袤天空与现代科技感。
   - **草原金 (Алтын сары - `#f59e0b`, `#fbbf24`)**：金阳与草原金雕的意象，点缀在图标、徽章、重要操作与边框。
   - **夜幕深蓝 (Түнгі көк - `#0a1120`, `#13213d`)**：深邃的草原夜空底色，配合夜间护眼模式。

2. **哈萨克传统纹样元素 (Ою-өрнек)**：
   - 顶部与背景巧妙融入了哈萨克经典羊角纹（**Қошқар мүйіз**）与金阳图腾矢量水印。
   - 卡片上沿融入蓝金渐变光条与专属哈萨克斯坦（KZ）国标徽章。

3. **品牌命名 (Бренд атауы)**：
   - **TúrLendir (Түрлендір)**：哈萨克语地道词汇，意为“转换”、“转码”，更符合本土互联网产品的命名习惯。

---

## 🌟 核心特性 (Негізгі мүмкіндіктер)

- **200+ 格式支持**：覆盖文档 (PDF, Word, TXT)、图片 (PNG, JPG, WEBP)、音频、视频、压缩包、表格、演示文稿及电子书。
- **纯浏览器端真实极速转换**：
  - 图像实时无损/可调质量互转（基于 HTML5 Canvas）
  - 文本与 Markdown 实时渲染导出标准 PDF 文档（基于 jsPDF）
  - 批量文件一键打包导出 ZIP（基于 JSZip）
- **哈萨克语参数微调面板 (Түрлендіру параметрлері)**：图像质量滑块、尺寸缩放、音频比特率、文档版式。
- **双主题模式 (Dark / Light)**：自由切换夜间深蓝与白天天空蓝模式。
- **坚戈 (₸) 本地化资费方案**：贴近哈萨克斯坦当地的计费体系展示。

## 🚀 启动与部署 (Іске қосу)

### 本地快速预览
在 Windows 资源管理器中直接双击 `index.html` 即可在浏览器中体验。

### 部署到 GitHub Pages
1. 在 GitHub 上新建仓库（如 `turlendir-kz`）。
2. 将本目录下的文件（`index.html`、`app.js`、`styles.css`、`README.md`）上传。
3. 在仓库 `Settings` -> `Pages` 中选择 `main` 分支并保存，即可获得全球可访问的正式网址！
